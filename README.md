# SafeMap 🛡️

Global Domestic Violence Awareness Dashboard - interactive map showing country-level data and resources.

**Live:** https://sahirvhora.github.io/safemap/

## Features
- Interactive global map with country-level statistics
- Resource directory for support services
- Quick Exit button and ESC-key escape route
- Dark theme, responsive design

## Tech
Vanilla HTML/CSS/JS - no frameworks. Open index.html in any browser.

## Data and Safety

See [DATA_SOURCES.md](DATA_SOURCES.md) for source selection rules, resource validation cadence, and the safety disclaimer. SafeMap should remain an awareness dashboard and should not store personal data or imply emergency guidance.
